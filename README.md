# Симулятор тестовой станции

Тестовый стенд для умного устройства (например, телевизора). Эмулятор изображает
реальное устройство, станция подключается к нему и прогоняет тестовые сценарии,
результаты можно получить через REST API и посмотреть в базе.

Проект учебный: писал его, чтобы разобраться, как устроена тестовая станция
целиком - от сетевого протокола до запуска на сервере.

## Что умеет

**Эмулятор устройства.** TCP-сервер, который понимает команды `PING`,
`GET_STATUS`, `SET_VOLUME <0-100>`, `STOP` и отвечает в JSON. Специально ведёт
себя как настоящее железо: с некоторой вероятностью отвечает с задержкой,
возвращает ошибку «устройство занято» или молча рвёт соединение.

**Ядро станции.** Подключается к эмулятору, прогоняет сценарии, собирает отчёт.
Отличает временные сбои (таймаут, обрыв связи, «занято») от окончательных: при
временных повторяет попытку, при окончательных сразу помечает сценарий
проваленным.

**REST API на FastAPI.** Запуск сценариев и получение результатов по HTTP.

**Запись в PostgreSQL.** Результаты прогонов складываются в базу, чтобы потом
можно было разбирать, что и почему падало.

**Заглушка MES.** Имитация фабричной системы, в которую станция отправляет
результаты - в двух вариантах, REST и SOAP.

**Тесты и CI.** Unit-тесты на pytest, прогон на каждый push через GitHub Actions.

**Деплой.** systemd-юниты для запуска компонентов как сервисов на Linux.

## Стек

Python 3.12, FastAPI, uvicorn, PostgreSQL (psycopg), httpx, lxml, pytest,
GitHub Actions, systemd.

## Как запустить

```bash
pip install -r requirements.txt
```

Настройки подключения к базе берутся из переменных окружения:
`DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.

Создать таблицу:

```bash
python src/bd/db_init.py
```

Дальше каждый компонент - в своём терминале.

Эмулятор устройства:

```bash
cd src/dut_emulator
python emulator.py
```

Заглушка MES (REST и SOAP):

```bash
cd src/mes
uvicorn mes_stud:app --port 8100
uvicorn mes_soap:app --port 8200
```

API станции:

```bash
cd src/dut_emulator
uvicorn station_api:app --port 8000
```

После этого документация API доступна на `http://127.0.0.1:8000/docs`.

Прогнать сценарии разово, без API:

```bash
cd src/dut_emulator
python station_core.py
```

## Тесты

```bash
pytest src/test_dut_emulator -v
```
